## 📊 ¿Qué hace este bot?

Este bot implementa la estrategia **Order Flow Breakout** inspirada en métodos de traders profesionales como el Trader Bro chino. Analiza:

✅ **Flujo de órdenes (Order Flow):** Detecta dónde se concentran las órdenes grandes  
✅ **Rupturas de precio (Breakouts):** Identifica niveles de soporte/resistencia  
✅ **Microestructura del mercado:** Analiza la profundidad del orden book  
✅ **Backtesting:** Simula resultados históricos antes de tradar real  
✅ **Sin comisiones externas:** Código abierto, solo pagas a Binance
